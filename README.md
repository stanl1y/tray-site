# Tray website

Public project information, support, and privacy policy for Tray, a temporary iPhone and Mac inbox. The app is preparing for its first release.

- Website: https://stanl1y.github.io/tray-site/
- Support: https://stanl1y.github.io/tray-site/support/
- Privacy: https://stanl1y.github.io/tray-site/privacy/
- English: https://stanl1y.github.io/tray-site/en/
- Contact: diiinkservice@gmail.com

Static HTML/CSS with no dependencies, analytics, forms, or payment flow. GitHub Pages publishes the `main` branch root. This repository contains only public website files, not the native app, signing configuration, development data, or credentials.

The privacy policy describes the current prerelease app. Update it when release features or data practices change.
